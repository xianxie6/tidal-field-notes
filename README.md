# 潮下笔记 / Below the Surface

一段基于 Three.js 的实时海底峡谷垂直切片。当前版本使用程序化几何和自制着色器验证水下空间、焦散、体积光、鱼群行为与柔和观察交互。

## 在线体验

网站发布完成后，可直接通过仓库首页的 Website 链接进入，无需安装。

## 启动

需要 Node.js 20.19+ 或 22.12+。

macOS 可以直接双击项目根目录中的 `启动潮下笔记.command`，它会启动本地服务并自动打开浏览器。

> 不要直接双击 `index.html`。Vite 项目需要经过本地开发服务器加载；直接打开只会看到未应用样式的原始文字。

```bash
npm install
npm run dev
```

终端会显示本地地址，通常为 `http://localhost:5173`。生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 移动鼠标：缓慢改变观察方向和潜水灯区域
- 滚轮：向峡谷深处推进或后退
- 在空白水体按住鼠标：持续缓慢推进
- 点击鱼：打开测试物种观察卡片
- `Esc`：关闭观察卡片
- 右上角 `HIGH / MED / LOW`：切换质量档位并重新载入

可通过 URL 强制指定质量，例如 `?quality=low`。

## 已实现

- 程序化海床、带侵蚀纹理的分层岩壁、礁面微附着物、碎石，以及渐细分叉、网状海扇和层叠盘状三类程序化珊瑚
- 珊瑚表面具有孔隙、矿物色差、生长端与生长环细节；海床叠加两级顺流沙纹
- 独立底栖生物层：异相摆动的海葵触手、海胆躯体与放射棘刺、贴沙生长的小型海星
- 人工构图的左右连续礁肩：左侧近景与右侧中景采用不同深度、密度和轮廓，避免镜像峡谷
- High 档约 100,000 根表面短藻；裸岩、藻毯、短藻与海绵共用真实表面位置和法线
- 深度雾化、破碎式动态海床焦散、静态阳光方向与柔边体积光幕
- 两层不同尺度与速度的浮游颗粒
- 100–260 条有体积鱼体，带背腹色差、鳃线、侧线、独立虹膜/瞳孔，并具有身体弯曲、转向惯性、侧倾、聚集、分离与光区避让行为
- High / Medium / Low 额外提供 54 / 36 / 18 条珠光礁鱼：蓝紫小型鱼、银铜圆腹鱼、透明细身群游鱼、银色圆盘鱼、高背长鳍神仙鱼和墨绿金鳞短身鱼；六类鱼具有独立身型、鳍形、鳞光、速度与水层
- 珠光礁鱼采用鱼体、半透明鳍和凸出眼球三层实例结构；薄鳍具有独立透光、鳍条与摆动，虹膜和瞳孔使用湿润清漆响应潜水灯
- 六类鱼体使用独立轴向轮廓而非缩放球体，并加入收窄尾柄、厚肩、吻部、实体嘴唇、鳃盖弧线、侧线、缓慢鳃呼吸和异步胸鳍划水
- 自制重叠鳞片高度纹理参与表面法线，稀疏银铜鳞光由观察角度驱动，不再以固定频率闪烁
- 一条成鱼与两条不同尺度幼鱼组成近景金目鲈小群，具有 PBR 贴图、独立摆尾相位、转向侧倾、伴游偏移和避让；远处程序化鱼群继续负责大规模群集行为
- 自制水下等距环境反射，让湿润鱼体与岩面共享同一套顶部光源信息
- 分离的顶部主光、海床反弹光与峡谷侧向填充，保留礁面暗部和覆盖层接触阴影
- 实例化海草和软珊瑚的异相顶点摆动
- 惯性镜头漂浮、鼠标潜水灯、滚轮/按住推进与射线观察；单击任意水域会建立三维群游目标，所有鱼以各自惯性向点击方向聚集
- 自动 High / Medium / Low 质量档位、窄屏降级、失焦暂停和低动态偏好

## 资产说明

近景主体使用 Khronos glTF Sample Assets 中的 Barramundi Fish（CC0-1.0），已压缩后本地托管，不热链远程资源。远景鱼群、岩石、海床、海草、珊瑚、焦散和粒子仍由代码程序化生成。来源、许可、原始大小与用途见 `docs/asset-candidates.md`。

关于官方 WebGPU 水面示例为何显得真实，以及它对本项目生物表现的启示，见 `docs/threejs-water-duck-study.md`。

## 工程说明

第一阶段使用稳定的 WebGL2 路线建立视觉基线。环境、鱼群、粒子、输入与相机系统彼此隔离，后续可将着色材质迁移到 TSL/WebGPU，同时保留 WebGL2 降级路径。
