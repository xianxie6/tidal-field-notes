# 第一阶段实施计划

## 目标切片

场景是一条由岩壁包围、中心略开阔的海底峡谷。镜头从近处暗色岩体之间进入，中景鱼群横穿阳光，远景由青蓝雾和轮廓收束。

## 阶段拆分

### 1. 基础工程与渲染骨架

- Vite + TypeScript + Three.js
- 场景、渲染器、相机、时钟与生命周期
- 质量档位、低动态偏好、失焦暂停、尺寸响应

### 2. 水体与空间证据

- 指数雾与距离色彩衰减
- 程序化海床着色器和移动焦散
- 多束近似体积光
- 两层不同尺度、速度和漂移方向的浮游颗粒

### 3. 峡谷构图与柔性生境

- 程序化海床、岩体实例和前中远景轮廓
- 人工控制的左侧近景与右侧中景连续礁肩，以及共享真实表面位置与法线的裸岩、藻毯、短藻和海绵群落
- 按礁面面积与生态覆盖率加权种植短藻；High / Medium / Low 全场分别约 100k / 44k / 12k 根
- 旧随机巨石降至原数量约 38% 并退到远景；高海草降至约 28% 并退出近景
- 分布于峡谷边缘的低饱和渐细分叉珊瑚、海扇和波浪边盘状珊瑚
- 实例化海草与顶点着色器异相摆动

### 4. 生物反馈

- 100–300 条实例化低面数鱼
- 空间哈希加速的聚集、对齐、分离与边界行为
- 个体摆尾相位、尺寸和色彩差异
- 对观察光区和相机的柔和避让
- 六类不同轮廓、鳍形、珠光鳞纹、速度与水层的礁鱼，整体配色受水体吸收约束
- 鱼体、半透明鳍和凸出眼球分层渲染；鳍条随摆尾形变，虹膜、瞳孔和清漆高光构成近景观察细节
- 六套轴向体型曲线替代通用椭球，加入尾柄、厚肩、吻部、嘴唇、鳃盖、侧线、鳃部呼吸和胸鳍异步划水
- 程序化重叠鳞片高度纹理参与法线计算，鳞片闪光转为视角相关响应
- 单击水域建立持续的三维吸引目标，程序化鱼群、珠光鱼和金目鲈保持各自惯性向目标汇聚
- 海葵、海胆和海星组成的独立底栖生物系统
- CC0 金目鲈成鱼与两条幼鱼组成近景材质基准，共享资产但使用不同尺度、摆尾相位、伴游偏移和游姿

### 5. 交互与观察笔记

- 鼠标控制观察方向与潜水灯
- 滚轮和按住空白处缓慢潜行
- 点击鱼类显示测试观察卡片
- 极简加载、操作提示、深度读数和质量切换

### 6. 验证与校准

- TypeScript 与生产构建
- 桌面和窄屏浏览器截图检查
- 控制台错误、Resize、交互和观察卡片检查
- 记录初步 FPS，并针对明显瓶颈降级

## 架构边界

- `core/UnderwaterExperience`：生命周期与系统编排
- `core/CameraRig`：惯性潜行与水下漂浮
- `core/QualityManager`：自动质量档位和性能采样
- `systems/EnvironmentSystem`：海床、峡谷、焦散、光柱和植物
- `systems/ReefSurfaceSystem`：人工构图礁壁、连续生态覆盖层和表面附着短藻
- `systems/ParticleSystem`：分层浮游颗粒
- `systems/FishSchoolSystem`：鱼群模拟、实例更新和射线目标
- `systems/ReefFishSystem`：多种彩色礁鱼的形体、花纹、分层巡游与避让
- `systems/HeroFishSystem`：近景 glTF 鱼、材质融合、摆尾、轨迹与避让
- `systems/BenthicLifeSystem`：海葵、海胆、海星的实例化几何与水流动画
- `systems/InputController`：鼠标、滚轮、点击与观察光区
- `ui/Interface`：加载、档位、深度和观察卡片

## 技术选择

第一阶段使用 Three.js `WebGLRenderer`，以最快速度建立稳定的视觉基线。着色器和场景系统均隔离于渲染生命周期，后续可把材质改写为 TSL 并接入 `WebGPURenderer`；WebGL2 保留为兼容路径。当前阶段不引入 React，外部资产仅保留一份已审核、压缩后约 363 KB 的近景鱼 GLB。

## 后续优先级

1. 用实拍参考校准水体吸收、光柱密度和材质粗糙度。
2. 用经过审核的多种鱼类补齐近中景体型差，并将静态形变升级为骨骼/形态目标动画。
3. 为程序化远景鱼群加入群体分裂/合并与更明显的速度差。
4. 建立 KTX2/Meshopt 资产管线，扩展观察笔记、拍摄与收录反馈。
