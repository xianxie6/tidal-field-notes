# 潮下笔记 / Below the Surface

## 产品目标

“潮下笔记”是一段可在浏览器中实时探索的自然纪录片式海底体验。第一阶段聚焦一条珊瑚峡谷：镜头缓慢潜行，阳光穿过水体，鱼群从光柱中游过并对观察者作出反应。

产品的单一核心体验是：让用户在进入页面后的数秒内，相信自己正悬浮于有深度、有水流、有生物反馈的真实水体，而不是观看一层蓝色滤镜覆盖的普通 3D 场景。

## 视觉原则

真实感优先级：

1. 水下光线、颜色衰减和空间层次
2. 生物运动的自然程度
3. 材质统一与环境融合
4. 观察行为与生物反馈
5. 模型数量与几何精度

基调采用深海墨青、低饱和蓝绿与少量砂金阳光。辉光、景深和颗粒只作为水体证据，不承担主要造型。避免霓虹、卡通水族馆、玻璃拟态卡片和过度游戏化的 HUD。

## 设计语言

- **色彩**：深渊墨 `#03141C`、峡谷青 `#0B3D46`、透光蓝 `#4C9A9A`、砂岩灰 `#52625B`、日光金 `#D9C58B`。
- **字体**：标题使用系统宋体/衬线体，正文使用清晰的人文无衬线体，读数使用等宽体。
- **界面**：以博物学野外记录的编号、细线与克制排版为线索，不做悬浮控制面板。
- **标志性瞬间**：观察光束扫入鱼群时，鱼群在光锥周围形成会自行闭合的短暂空腔。

## 第一阶段边界

只交付一个精致的可探索峡谷垂直切片。程序化几何承担海床、岩体、植被与鱼类占位；不引入来源不明的外部模型、贴图或音频。观察卡片只验证后续“海底观察笔记”的交互方向。

## 可访问性与性能

- 以桌面 Chrome 1080p、45–60 FPS 为目标。
- 支持 High / Medium / Low 三档质量并自动选择初始档位。
- 窄屏自动使用 Low；页面失焦时暂停渲染。
- `prefers-reduced-motion` 下减弱镜头漂移、粒子速度和植被摆动。
- 所有必要操作提示使用 HTML，交互按钮可键盘聚焦。
