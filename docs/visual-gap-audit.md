# 视觉差距审查：Sylva → 潮下笔记

参考对象：[Sylva — Into the living world](https://mengto.github.io/sylva/)

本文件只记录视觉方法，不复制参考项目源码、几何、纹理或艺术资产。

## 真实感差距

### 参考作品有效的部分

- 主体轮廓由大量微小叶片覆盖，近看仍有表面尺度信息。
- 阴影保留中间调，物体既有体积又没有坠入纯黑剪影。
- 前景、中景和背景都存在不同密度的几何，而不是只有雾的颜色变化。
- 空气透视与柔边光束共同工作；光束不出现清晰的多边形边界。
- 大形体、微细节和稀疏粒子有明显尺度差，画面因而显得巨大。

### 当前海底版本的问题

- 鱼体由少量尖锐三角面组成，靠近镜头后像纸飞机。
- 岩体使用相同低细分球体，表面缺少侵蚀、藻类和附着物。
- 海草与软珊瑚轮廓接近直棒，缺少分叉和密度变化。
- 焦散是连续且规则的发光线，水面折射感不足。
- 体积光使用硬边锥体，边界暴露了近似方法。
- 暗部压得过黑，材质颜色和空间雾无法进入阴影。

## 本轮修正原则

1. 用光滑梭形鱼体、鳍和柔性尾部替换纸片轮廓。
2. 岩体提高细分并加入程序化侵蚀色差，同时增加礁面微型附着物。
3. 把海草改成有宽度的柔性叶片，把软珊瑚改成分叉结构。
4. 焦散改成多频域扭曲的破碎光斑，并降低整体亮度。
5. 光柱改成柔边平面光幕，消除三角形硬边。
6. 提升环境补光、降低雾密度，让阴影保留可辨识的材质层次。

## 不采用的部分

- 不复刻 Sylva 的森林造型、卡片布局、品牌配色或页面结构。
- 不下载其图片、字体、Three.js 文件或任何其他资源。
- 不把植物叶片直接替换为“海底版树叶”；细节必须符合礁岩、藻类和珊瑚的尺度逻辑。
